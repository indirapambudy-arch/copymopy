# TextArea

A multi-line TextField for the main prompt: describe the copy you need, or paste copy to rewrite.

- Same states, label, helper, error and counter as TextField (from the Figma text-area set).
- Starts at 88px (about 3 lines) and resizes vertically. Pass `rows` to change the start height.
- In the Microcopy lab, keep `maxLength` on: it caps API cost and tells people how much fits.
