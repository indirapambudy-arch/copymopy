# IconButton

A square, icon-only button for small repeated actions: copy, regenerate, clear.

- `label` is required. It becomes the `aria-label` and the tooltip, because the icon alone has no accessible name.
- Sizes: `md` 44px (default, meets the touch-target minimum) and `sm` 36px for dense spots like the result-card header.
- grey-main icon; grey-bgdisabled fill on hover; `focus-ring` on keyboard focus.
- Added for the Microcopy lab; not in the Figma file.
