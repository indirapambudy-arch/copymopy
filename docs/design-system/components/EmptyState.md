# EmptyState

What the results area shows before the first generation: an icon, a title and one line on how to start.

- Dashed grey-tertiary border on white-main, radius-md, centered.
- Title: subheading-18-bold. Text: caption-14 in grey-secondary, at most two lines.
- Tell people the next step, not that nothing is there: "Your options will show up here", then how to get them.
- `action` can hold a Button, for example "Try an example".
